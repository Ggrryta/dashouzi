# 秒杀系统

**技术栈：** Go + Gin + MySQL 8.0 + Redis 7 + Kafka + Docker

**项目描述：** 高并发秒杀系统，解决「不超卖 + 扛得住 + 可扩展」三大核心问题。Redis 原子扣减保证库存一致性，Kafka 异步削峰解耦订单创建。

**核心亮点：**
- **Redis Lua 原子扣减**：将「检查库存 + 扣减 + 记录用户」封装为单条 Lua 脚本，Redis 单线程执行，彻底杜绝超卖
- **Kafka 异步下单**：扣减成功后投递消息到 Kafka，消费者异步写 MySQL 创建订单。百万 QPS 请求削峰为 DB 可承受的写入量
- **令牌桶限流**：单用户 N 秒内只能请求一次，防止脚本刷单
- **库存预热**：秒杀开始前将库存从 MySQL 加载到 Redis 哈希表，避免秒杀瞬间 DB 查询瓶颈
- **对账脚本**：Redis 剩余库存 + MySQL 订单数 = 总库存，定时校验数据一致性

**工程实践：** Docker Compose 五服务编排 | Kafka KRaft 模式（无 ZooKeeper） | GORM 仅用于订单写入

**测试：** 单元测试 + Docker 集成测试，验证并发不超卖
