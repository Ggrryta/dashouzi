# 产品需求文档（PRD）

> Tech Coach — AI 驱动的技术面试训练平台
> 版本：v1.0 | 更新：2026-08-26

---

## 1. 产品定位

### 一句话
**用 AI Agent 当教练，通过苏格拉底式追问训练学生掌握技术能力。不是给答案，而是逼你思考。**

### 和竞品差异

| | 面试鸭/牛客 | Tech Coach |
|---|---|---|
| 学习方式 | 看题→看答案→背 | 被追问→自己想→纠错 |
| 知识体系 | 公共题库（标签） | **私有知识地图（记你的薄弱点）** |
| 交互 | 浏览答案 | **对话式训练** |
| 个性化 | 几乎没有 | **能力清单 + 打勾进度 + 薄弱点追踪** |
| 内容质量 | UGC为主 | **结构化追问策略（核心壁垒）** |

### 差异化定位（一句话）
> "不是刷题，是陪练。不是背答案，是被追问。"

---

## 2. 目标用户

- **主要**：秋招学生（计算机专业，准备后端/全栈面试）
- **次要**：跳槽的初中级程序员
- **特征**：不缺题和答案（面经到处有），缺的是"被追问逼着思考"的体验

---

## 3. 核心功能

### 3.1 Agent 教练（核心）
- 选一个场景 → AI 出题（业务背景 + SQL + 症状）
- 学生回答 → AI 追问/纠错/给提示
- 分层追问（L1预判→L2读计划→L3定位→L4方案→L5对比）
- 答错给最小提示，不直接喂答案
- 训练结束自动生成笔记

### 3.2 能力清单 + 打勾进度
- 每个领域一个结构化考点清单（如 MySQL 66项）
- 每完成一个场景，相关考点自动打勾
- 进度条可视化

### 3.3 私有知识地图
- 记录每个用户的薄弱点
- 自动沉淀训练笔记
- 间隔重复复习提醒

### 3.4 场景驱动训练
- 每个考点对应真实业务场景（订单慢、深分页、JOIN慢等）
- 不是"先讲原理再做题"，而是"遇到问题→分析→学原理"

## 4. 知识库结构

```
知识库
├── 考点图（知识点 + 依赖关系 + 难度 + 面试频率）
├── 场景库（真实业务问题 + 表结构 + 数据量 + 症状）
├── 原理库（技术原理准确讲解 + 官方文档引用 + 向量embedding）
├── 追问策略库（分层追问 + 提示策略 + 常见错误应对）← 核心壁垒
├── 标准答案库（执行计划 + 根因 + 优化方案 + 前后对比）
├── 面经库（考点出现频率 + 追问链）
└── 用户笔记库（UGC，成熟期）
```

### 知识库构建路线
- **种子库**：手动写核心场景（MySQL已有8个）
- **LLM扩展**：基于种子生成相似场景 + 人工审核
- **面经提取**：爬取公开面经，LLM提取考点（不抄内容）
- **社区沉淀**：用户训练笔记优质者入库

### 法律边界
- ✅ 提取"考点"（事实，不受版权保护）
- ✅ 引用官方文档改写
- ❌ 不抄面试鸭/小林coding等内容

## 5. 商业模式

### 订阅制（具体待定，候选方案）

| 方案 | 免费 | 付费 |
|------|------|------|
| A | 每天3次Agent教练 | 无限 |
| B | 基础场景 | 进阶场景+原理深度 |
| C | 无知识地图 | 私有知识地图+复习推送 |

**倾向**：A+C 组合（免费体验+限次，付费解锁无限+知识地图）

### 变现路径
1. **订阅**：月费/季费/年费
2. **企业版**：培训机构/学校批量授权
3. **内容授权**：追问策略库授权给其他平台

┌──────────────────────────────────┐
│        前端（Next.js）            │

└──────────────┬───────────────────┘

│  ┌──────────┐ ┌────────┐         │
│  │ 训练引擎  │ │清单管理│         │

│  ┌────┴───────────┐              │
│  │  RAG 检索层     │              │
│  └────┬───────────┘              │
│  ┌────┴───┐ ┌──────────┐        │

### 技术选型

| 层 | 技术 | 理由 |
|----|------|------|
| 前端 | Next.js 16 + Tailwind v4 + Framer Motion | 炫酷动效、SSR |
| 后端 | Go 1.25 + Gin | 性能、并发 |
| 数据库 | PostgreSQL 15 + pgvector | 关系+向量一个库 |
| LLM | OpenAI协议兼容 | 接口隔离，随时换国产 |
| 部署 | Docker Compose | 初期简单 |

## 8. 核心壁垒

### 追问策略库
- 每个场景的分层追问（L1~L5）
- 常见错误检测 + 针对性应对
- 这是**教学方法论**，不是LLM能力
- 别人抄不走——需要懂教育+懂技术的人写

### 私有知识地图
- 用户使用越久，薄弱点数据越多
- 积累的私有数据让用户离不开

### 结构化知识库
- 不是UGC堆砌，是结构化的考点+场景+原理+策略
- 质量可控，训练体验一致
