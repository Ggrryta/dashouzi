### 核心设计决策

1. **训练引擎是代码控制，不是prompt自由发挥** — 追问流程用结构化策略控制
2. **领域无关架构** — 所有数据带domain标签，换领域只换数据不换引擎
3. **追问策略库是核心壁垒** — 教学方法论，别人抄不走
4. **原理库+RAG保证技术准确性** — Agent纠错引用原理库，不让LLM编
5. **LLM接口隔离** — Provider接口，随时切换OpenAI/智谱/通义
